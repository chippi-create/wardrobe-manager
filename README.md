# wardrobe-manager

手持ちの服とコーデを管理する、スマホ向けのWebアプリです。

## できること

- **服の登録**：写真（自動で縮小）・名前・カテゴリ・色・シーズン・暖かさ・シーン・ブランド・サイズ・状態・メモ
- **メルカリと同じカテゴリ**：「レディース ＞ トップス ＞ シャツ/ブラウス(七分/長袖)」のように、メルカリの分け方で登録
- **メルカリ出品の下準備**：商品名と説明文を自動で作ってコピー、写真の保存、ステータス（所持中・出品中・売却済み）の管理
- **コーデ提案**：現在地の天気（またはスライダーで決めた気温）とシーンから、手持ちの服で組み合わせを提案
- **家族の管理**：メンバーを切り替えて、家族それぞれの服とコーデを1台で管理。持ち主の変更（お下がり）にも対応
- **一覧と絞り込み**：種類・色・シーズン・ステータス・キーワードで絞り込み、よく着る順／着ていない順に並べ替え
- **コーデ**：登録した服を組み合わせて保存
- **着用記録**：「今日着た」で記録。コーデで記録すると、含まれる服にも記録されます
- **バックアップ**：データ（写真込み）をJSONファイルに書き出し・読み込み
- **ホーム画面に追加**：PWA対応。オフラインでも開けます

### コーデ提案のしくみ

アプリ内のルールで選んでいます（AIや外部サービスは使っていません）。

- 気温から、トップス・ボトムス・アウターそれぞれのちょうどよい「暖かさ」を決める（`js/suggest.js` の `planFor`）
- 選んだシーン用に登録された服を優先し、別のシーン専用の服は除外。シーン未設定の服はどのシーンにも使う
- 今の季節に合う服、最近着ていない服を優先し、差し色が3色以上にならないようにする
- 最高気温と最低気温の差が大きい日は羽織りを、雨の日は長靴・レインシューズを提案に入れる

天気は [Open-Meteo](https://open-meteo.com/)（無料・登録不要）から取得します。送るのは約1km単位に丸めた緯度経度だけです。

### メルカリのカテゴリについて

カテゴリ一覧は `js/categories.js` にまとめています。メルカリ側で分類が変わったときは、このファイルを更新してください。
メルカリには個人向けの出品APIがないため、自動出品はできません。作った文章をコピーして、メルカリのアプリに貼り付けて使います。

## データの保存場所

データは使う人それぞれの端末のブラウザ（IndexedDB）にだけ保存され、サーバーには送られません。
機種変更やブラウザのデータ削除で消えるため、設定画面からときどきバックアップを書き出してください。

## 構成

ビルド不要の HTML / CSS / JavaScript（ES Modules）です。

```
index.html            画面
styles.css            見た目（ライト／ダーク対応）
js/app.js             画面の動き
js/db.js              IndexedDB への保存
js/image.js           写真の縮小・変換
js/categories.js      メルカリのカテゴリと商品の状態
js/suggest.js         コーデ提案のルール
js/weather.js         天気の取得
js/listing.js         出品用の商品名・説明文
sw.js                 オフライン用のキャッシュ
manifest.webmanifest  ホーム画面に追加するための設定
icons/                アプリアイコン
```

## 手元で動かす

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 公開

Cloudflare Workers（静的アセットのみ）で公開しています。

- URL：https://wardrobe-manager.cps-create.workers.dev
- `main` にプッシュするたびに自動で更新されます

これからの方針は [docs/ROADMAP.md](docs/ROADMAP.md) にまとめています。

アプリを更新したときは、`sw.js` の `CACHE` のバージョン（`wardrobe-v1` など）を上げると、使っている人の端末に新しい版が確実に届きます。
